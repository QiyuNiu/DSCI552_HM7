# DSCI 552 Homework 7

This folder contains Qiyu Niu's Homework 7 submission.

## Contents

- `notebook/Niu_Qiyu_HW7.ipynb`: completed and executed homework notebook
- `data/Frogs_MFCCs.csv`: Anuran Calls MFCC data
- `data/Readme.txt`: dataset description
- `requirements.txt`: Python packages used by the notebook

## Run

Install the dependencies from the repository root:

```bash
python -m pip install -r requirements.txt
```

Run Jupyter from the notebook folder so the relative data path stays correct:

```bash
cd notebook
jupyter notebook Niu_Qiyu_HW7.ipynb
```
